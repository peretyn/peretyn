`peretyn build` rejects schemas that the runtime would reject, such as an unknown type, an undefined relation or a permission that can never be granted, and prints the file position of the mistake. `any()` and `intersect()` with one operand compile to that operand. When the schema module can't load, the CLI shows Node's error, with a hint for ES modules in a CommonJS package.
