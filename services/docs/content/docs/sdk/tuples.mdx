## Idempotent writes

By default, writing a tuple that already exists and deleting one that doesn't exist both succeed without changing anything. You can make either case an error:

| Option        | Effect                                                             |
| ------------- | ------------------------------------------------------------------ |
| `onDuplicate` | `'ignore'` (default) or `'error'` when a written tuple exists.     |
| `onMissing`   | `'ignore'` (default) or `'error'` when a deleted tuple is missing. |
| `strict`      | Sets both options to `'error'`.                                    |

The SDK retries a write only when both options are `'ignore'`. A strict write runs once.

`written` and `deleted` count the tuples that you sent, not the tuples that changed.

## Read changes

`readChanges` pages through every write and delete in the environment, oldest first. Pass `type` to see changes to one object type only. Pass the `continuationToken` from one page to get the next.
