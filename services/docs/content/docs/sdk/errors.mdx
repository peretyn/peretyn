| Error                     | Thrown when                                                                                                     |
| ------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `PeretynError`            | The runtime answered with an error status. It has `status` and `body`. `assert` throws it with `403` on a deny. |
| `PeretynUnavailableError` | The SDK couldn't reach the runtime.                                                                             |
| `PeretynTimeoutError`     | The call ran out of `timeoutMs`. It extends `PeretynUnavailableError`.                                          |
