You need Node.js 24 or later, and Docker with ports 80 and 443 free. A managed Peretyn, with nothing to run yourself, is coming soon.

## Start Peretyn

Run the installer as any user that can run `docker`:

```sh
curl -fsSL https://peretyn.dev/install | sh
```

The only answer you type is your email, for the admin account. Press Enter at every other question: it keeps the default install directory and the `localhost` domain, skips the optional name and email key, and confirms the install. When the installer finishes, it prints the admin password once. Copy it: you sign in with your email and this password in step 1.

Peretyn now runs at `http://localhost`. Set that address once, and the steps below use it:

```sh
export PERETYN_URL=http://localhost
```

This install serves plain HTTP, so use it only from this machine. To run Peretyn on a server with your own domain, see [Self-hosting](/self-hosting), and use your domain as `PERETYN_URL`, such as `https://peretyn.example.com`.
