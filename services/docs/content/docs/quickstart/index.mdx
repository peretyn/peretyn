---
title: Quickstart
description: Publish a schema and run your first check on your own Peretyn.
---

You need Node.js 24 or later, and a running Peretyn. To start one on your machine, follow [Try it on this machine](/self-hosting#try-it-on-this-machine). Then set its address once, and the steps below use it:

```sh
export PERETYN_URL=http://localhost
```

If Peretyn runs on a server, use its domain instead, such as `https://peretyn.example.com`.

A managed Peretyn, with nothing to run yourself, is coming soon.
