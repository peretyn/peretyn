You need Node.js 24 or later, and access to a Peretyn dashboard. The managed dashboard is at [app.peretyn.dev](https://app.peretyn.dev). If you run Peretyn yourself, use your own domain in place of `app.peretyn.dev` below.

## 1. Create a project

In the dashboard, select **Create project**. Peretyn creates a `production` and a `development` environment and shows an API key for each. Copy the `development` key, which starts with `prn_test_`. The dashboard shows it only once.

## 2. Set your environment

The SDK and the CLI both read these variables:

```sh
export PERETYN_TOKEN=prn_test_...
export PERETYN_RUNTIME_URL=https://app.peretyn.dev
export PERETYN_CONTROL_URL=https://app.peretyn.dev
```

## 3. Install the SDK

```sh
npm install @peretyn/sdk
```

## 4. Write a schema

A document has owners and viewers. Anyone who is an owner or a viewer can view it.

## 5. Publish the schema

Download the `peretyn` binary for your platform from the [latest release](https://github.com/peretyn/peretyn/releases) and put it on your `PATH`. Then compile the schema and publish it to the environment that your API key identifies:

```sh
peretyn build --schema schema.ts
peretyn apply --label v1
```

## 6. Run a check

This script writes one tuple, Alice owns the roadmap, and then checks whether Alice can view it:

<include>../../snippets/quickstart/check.ts</include>

```sh
node check.ts
```

It prints `allowed`. Alice is an owner, and owners can view.
