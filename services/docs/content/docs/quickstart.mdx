You need Node.js 24 or later, and access to a Peretyn dashboard. Set its address once, and the steps below use it:

```sh
export PERETYN_URL=https://app.peretyn.dev
```

If you run Peretyn yourself, use your own domain instead, such as `https://peretyn.example.com`.

## 1. Create a project

Open the dashboard at `$PERETYN_URL`. If you have no organization yet, select **Create organization** and name it. Then select **Create project**.

Peretyn creates a `production` and a `development` environment and shows an API key for each. Copy the **Development key**, which starts with `prn_test_`. The dashboard shows each key only once.

The dashboard opens on Production. To see the tuples that this quickstart writes, switch the environment selector to Development.

## 2. Set your environment

The SDK and the CLI both read these variables:

```sh
export PERETYN_TOKEN=prn_test_...
export PERETYN_RUNTIME_URL=$PERETYN_URL
export PERETYN_CONTROL_URL=$PERETYN_URL
```

## 3. Install the CLI and the SDK

Install the CLI. It goes to `~/.local/bin`, which must be on your `PATH`. See [CLI](/cli) for the options:

```sh
curl -fsSL https://peretyn.dev/install-cli | sh
```

Then create a project directory. The schema and the scripts are ES modules, so set `type` to `module`:

```sh
mkdir peretyn-quickstart
cd peretyn-quickstart
npm init -y
npm pkg set type=module
```

Install the SDK:

```npm
npm install @peretyn/sdk
```

## 5. Publish the schema

Compile the schema and publish it to the environment that your API key identifies:

```sh
peretyn build --schema schema.ts
peretyn apply --label v1
```

## 6. Run a check

This script writes one tuple, Alice owns the roadmap, and then checks whether Alice can view it:

<include>../../snippets/quickstart/check.ts</include>

```sh
node check.ts
```

It prints `allowed`. Alice is an owner, and owners can view.
