# Security policy

Peretyn makes authorization decisions, so we treat security reports as our highest priority.

## Supported versions

Peretyn is pre-1.0. We fix security issues only in the latest release.

## Reporting a vulnerability

Do not open a public issue, pull request or discussion for a vulnerability.

Report it privately through GitHub: go to the [Security tab](https://github.com/peretyn/peretyn/security) and select **Report a vulnerability**.

Include:

- The affected component (SDK, CLI, runtime, control, dashboard or the self-hosting stack) and version
- Steps to reproduce, or a proof of concept
- The impact, for example an incorrect allow decision or data from another project

We aim to acknowledge your report within 3 business days. We will keep you informed while we work on a fix, and we will credit you in the advisory unless you ask us not to.
